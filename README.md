# Kebun59 — Nursery Management

Aplikasi dashboard operasional pembibitan tanaman berbasis HTML, CSS, dan JavaScript.

## Fitur
- Dashboard ringkasan stok, jenis tanaman, penjualan, dan pengguna aktif.
- Data tanaman: tambah, edit, hapus, pencarian, dan filter kategori.
- Transaksi penjualan dan pembelian.
- User management: tambah, edit, peran, dan status pengguna.
- Laporan nilai persediaan, penjualan, pembelian, dan komposisi kategori.
- Penyimpanan data demo di browser menggunakan localStorage.

## Menjalankan
GitHub Pages dapat digunakan untuk menayangkan aplikasi statis ini. Aktifkan melalui Settings → Pages, pilih branch `main` dan folder `/(root)`.

## Catatan
Ini adalah prototipe frontend. Data tersimpan lokal di browser masing-masing dan belum memiliki autentikasi sungguhan, backend, database bersama, audit log, atau kontrol akses sisi server. Untuk operasional multi-user, hubungkan ke API dan database serta implementasikan autentikasi dan role-based access control di server.
